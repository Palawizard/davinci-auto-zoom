THE FOUR HARD NEGATIVES
-------------------------

Both policies must explain these, and only one row is explained for the right reason.

    gap  1   creator: friends talk, nothing new visible
             9a: FALSE POSITIVE (it proposes gameplay everywhere)
             9b: correct verdict, wrong reason — it reports `outside the ROI` for a
                 window whose real property is that nothing is happening

    gap 10   creator: an event exists, zooming adds nothing
             9a: FALSE POSITIVE
             9b: CORRECT, and for exactly the creator's reason — the event covers the
                 frame, so `event_covers_the_whole_frame` fires. The one row where a
                 measurement and the creator's sentence say the same thing

    gap 11   creator: the friend's subject is not on screen
    gap 12   creator: the friend's subject is not on screen
             9a: FALSE POSITIVES
             9b: correct verdict, wrong reason — the corridors are empty, and the
                 metric calls the player's own camera pan a full-frame event

So Phase 9b gates all four, and eight of the ten positives with them. A rule that
refuses almost everything gets the negatives for free; that is not a solved rule, and
it is not proposed as one.


ABLATION 2.0 — SIX FAMILIES, ONE CODE PATH
--------------------------------------------

Every family is `decide_gameplay` with different switches, run live over the same 15
windows. `gameplay_by_default` is off in all of them, so each measures what its signals
explain on their own.

    family                            correct   false +              false -
    A phase9a silence+audio+video      8/15   [1, 10, 11, 12]      [0, 9, 13]
    B visual amount only               8/15   [10, 11, 12]         [0, 3, 9, 13]
    C visual spatial                   7/15   []                   [0, 3, 4, 5, 6, 7, 8, 9]
    D spatial+silence prior            6/15   []                   [0, 2, 3, 4, 5, 6, 7, 8, 9]
    E spatial+audio context            6/15   []                   [0, 3, 4, 5, 6, 7, 8, 9, 13]
    F spatial+silence+audio            5/15   []                   [0, 2, 3, 4, 5, 6, 7, 8, 9, 13]
    candidate rule (no signal)        11/15   [1, 10, 11, 12]      []
    majority baseline                 10/15

Reading it honestly:

  * nothing beats the no-signal candidate rule, and only the baseline ties it;
  * adding signals makes it *worse*, monotonically: C 7, D 6, E 6, F 5. Each extra
    AND-gate removes true positives and no false ones, because C already has none;
  * C to F have **zero false positives** — every X0 window is refused, including all
    four hard negatives. That looks like the phase's goal and is not: they also refuse
    8 of the 10 gameplay windows. Precision without recall on a 10/5 split is just a
    conservative rule;
  * B (visual amount only) still scores 8 and still fails on 10/11/12, unchanged from
    Phase 9a — the spatial reading did not fix what the amount got wrong, it failed
    somewhere else.

The smallest set that explains the hard negatives is therefore **none of them**. What
explains the hard negatives is the creator's sentences, and no feature measured in
Phase 9a or 9b reproduces three of the four.
